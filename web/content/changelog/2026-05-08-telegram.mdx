Blipko started life on WhatsApp. It now lives in **Telegram**, which means no
business-API gatekeeping, instant slash commands, and a chat that opens on every
device you already own.

- **Log spends by chatting.** Send `chai 30` and it's recorded. Malayalam,
  Manglish and English all work, by text or by voice note.
- **Slash commands** for the things you do often — `/help` to see everything.
- **One-tap account linking.** Open the dashboard, tap Connect, and the bot
  opens already signed in as you. No copying codes between screens.

### Also in this release

- A Kerala-first landing page, written for people budgeting in rupees.
- Deployed on Railway, so the bot answers immediately instead of cold-starting.
- Security pass across both the bot and the web app: ownership checks on every
  record, timing-safe token comparison, and escaped Telegram markdown.
